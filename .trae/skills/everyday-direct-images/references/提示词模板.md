# 审核与执行提示词模板（Review and Execution Prompt Template）

请使用以下输出结构。仅在某一部分确实与当前任务完全无关时才予以省略。

## 审核输出包

```text
【创作理解】
用简洁语言归纳最终要生成的画面、用途和核心叙事。

【参考图角色】
- 主体主参考图：……
- 主体辅助参考图：……
- 主要风格参考图：……
- 次要风格参考图：……

【风格解析】
- 稳定特征：……
- 可选特征：……
- 不应迁移的画面内容：……
- 不确定内容与可信度：……

【主体锁定清单】
列出必须保持不变的身份、结构、比例、姿态、配色、材质、标记及关键细节。

【允许变化范围】
列出用户授权改变的内容，未列出的主体属性保持不变。

【合理推断】
列出为了形成完整画面而新增、且已获用户授权自行决定的内容。

【电影化控制】
- 叙事瞬间：一句话说明画面发生前后或即将发生的关键变化。
- 第一视觉锚点：观众第一眼必须看到的唯一主体或动作。
- 辅助信息：最多一至两个用于交代尺度、地点或张力的次级元素。
- 视线动线：说明光线、明暗、透视、动作或边缘如何引导观看顺序。
- 空间分层：分别定义前景、中景、背景的功能、清晰度、反差和信息密度。
- 细节预算：说明高频细节集中区域、需要简化的区域，以及保留大片安静形体的位置。
- 光线动机：说明主光源从何而来、照亮什么，以及辅助光如何服从主光。
- 镜头克制：说明机位与焦段的叙事作用；光晕、颗粒、景深等只作为次级处理。

【中文审稿版提示词】
写成完整、连贯、可审核的生图指令。先保证叙事锚点、大片形、视线动线、空间分层与细节预算，再按实际需要组织主体、动作、环境、景别、机位、镜头、灯光、颜色、美术、材质、影像介质、后期和情绪。不要机械堆砌无关维度，不要把所有表面、碎片和背景同时写成高细节。

【英文执行版提示词】
忠实翻译并优化为可执行英文，但不得增加中文版本中没有的视觉内容。

【负面约束】
列出需要避免的身份漂移、结构错误、额外元素、文字错误、风格冲突及其他具体问题。

【画幅建议】
用户未指定时采用默认 `21:9` 并说明理由。其他比例只能作为可选推荐；用户已明确指定时，以用户选择为准。

【输出规格】
- 用途：最终成片、海报、桌面壁纸、社交媒体或其他明确用途。
- 画幅：用户已确认的宽高比；未指定时使用默认 `21:9`。
- 目标像素：默认采用技能规定的 4K 级尺寸；明确写出 `宽 x 高`，并说明这是目标规格而非无尺寸控制工具的保证值。
- 质量：最高可用原生质量；边缘清晰、材质层次真实、细纹理自然，不用全画面微细节堆砌制造虚假清晰度。
- 后期约束：胶片颗粒应细腻且受控，避免过度锐化、光晕边、塑料质感、涂抹感和压缩伪影。

【画面文字】
- 主标题：……
- 副标题：……
- 标语：……
- 署名或小字：……
- 对应翻译：……

状态：待确认，暂不生成图片。
create by @drakefif
```

## 提示词构建顺序

在有助于清晰表达时，可以参考以下灵活顺序：

`叙事瞬间 → 第一视觉锚点 → 大形体构图 → 视线动线 → 空间分层 → 细节预算 → 主体与动作 → 环境设定 → 景别/机位 → 光线动机 → 克制色彩 → 镜头特性 → 材质表现 → 影像介质 → 原生分辨率与纹理质量目标 → 后期处理 → 约束条件`

除非属于已获用户授权决定的“合理推断”，否则不要提及当前输入中没有依据的属性。

在英文执行提示词末尾，用可操作语言重申视觉层级与精简去杂（decluttering）约束。切勿追加未获批准的额外粒子、碎屑、损伤、道具、光源或光学特效。

在双语版本中以语义形式表达已确认的输出质量目标。例如，中文使用 `4K级最终母版、原生高分辨率质感、边缘干净、细纹理自然、胶片颗粒受控、避免过度锐化`，对应英文使用 `4K-class final master, native high-resolution rendering, clean edge definition, natural fine texture, controlled film grain, no oversharpening`。此表述旨在引导视觉质感；生成后仍须从文件元数据中验证实际像素尺寸。

## 修改重出规范

收到用户修改反馈后，重新打印包含修改且已消除矛盾的完整审核包，不要仅输出修改片段的对比。在用户明确批准生成前，状态行保持为 `待确认，暂不生成图片。`，并始终以 `create by @drakefif` 作为最后一行。

## 批准后的响应

收到用户的明确批准后，使用最终确认的提示词进行生成或编辑。不要就同一份未经更改的提示词要求用户二次确认。在面向用户的所有批准确认、生成进度、最终结果及审查反馈的回复中，始终以 `create by @drakefif` 作为独立结尾行。
